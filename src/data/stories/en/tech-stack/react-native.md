My main experience with React Native came from one specific project in 2025: SettleItGPT.

I built the project with a friend, and the entire application was developed with React Native and Expo.

SettleItGPT was a fairly complex iOS application. Users could create accounts, their data was stored in Firebase, and the app used native device capabilities like the camera, microphone, and photo library.

Information collected from the user was sent to an LLM, the model generated a response, and in parts of the application another model converted the generated text into speech so the result could be delivered directly inside the app.

The app also had a subscription system, with purchases handled through Stripe.

It wasn't an easy project for me.

Unlike many other technologies I learned gradually by experimenting with smaller projects first, with React Native I was dropped almost directly into a real product and had to learn whatever the project needed while I was building it.

Because of that, React Native, Expo, and especially some of the native parts caused me plenty of trouble along the way.

But the final result was really good.

The app worked, all the different systems came together, and we eventually managed to publish the finished product on the Apple App Store.

My relationship with React Native is much more neutral than my relationship with something like React.

I never really went through the slow, step-by-step learning process I usually enjoy with a technology. I mostly learned it because the project demanded it and kept moving forward from there.

But that project also proved to me that I can work with React Native and take a relatively complex mobile product all the way to release.

At the end of the day, React Native is still built around JavaScript and a way of thinking I'm already very comfortable with.

So it may not be one of my favorite technologies, but if another project needs it, I know I can work with it and get the job done.
