یادگیری JavaScript رو سال ۲۰۲۲ و تو ادامه دوره CS Internship شروع کردم.

اون موقع تازه داشتم با HTML و CSS خو می‌گرفتم که یهویی یه زبون جدید اومد جلوم نشست. زبونی که ساختار و مدل کار کردنش با HTML و CSS کاملا فرق داشت.

یادگیریش رو تو مسیر دانشگاه، با ویدئوهای YouTube، کتاب You Don't Know JS و بیشتر از همه سایت W3Schools پیش می‌بردم. فکر کنم نزدیک ۹۰ درصد چیزهایی که اون موقع یاد گرفتم از همین W3Schools بود!

یاد گرفتنش هم سخت بود، هم راحت. من قبلش با C++ کار کرده بودم و با منطق برنامه‌نویسی و مدل فکر کردنش آشنا بودم، ولی JavaScript باز هم برام فرق داشت. یادمه وقتی دانشگاه می‌رفتم، روی شست دستم کلمه JS می‌نوشتم که یادم بمونه الان هدف اصلی یادگیریم این زبانه. می‌خواستم تو طول روز تو ذهنم باشه و مدام چیزهایی که یاد گرفته بودم رو مرور کنم.

یه دفتر ۶۰ صفحه‌ای هم داشتم که تبدیلش کرده بودم به دیکشنری شخصی JavaScript خودم. هر چیز جدیدی یاد می‌گرفتم رو خیلی خوشگل و با سلیقه توش می‌نوشتم و مدام برمی‌گشتم سراغش تا چیزهایی که قبلا یاد گرفته بودم رو هم دوره کنم.

یادگیریم از همون اول کاملا پروژه‌محور بود. مثل تقریبا همه چیزهای دیگه‌ای که یاد گرفتم، یه Repository به اسم Learning JS داشتم. هر مفهوم جدیدی، حتی ساده‌ترین چیزها رو توش کد می‌زدم، خروجیش رو می‌دیدم، تغییرش می‌دادم و باهاش بازی می‌کردم. سعی می‌کردم به چالشش بکشم تا بالا و پایینش دستم بیاد.

بعد از یه مدت اولین پروژه‌ای که واقعا با JavaScript ساختم، یه Todo App بود. کل اپ رو تو حدود ۳ یا ۴ ساعت ساختم، از پروسه ساختنش یه تایم‌لپس خوشگل درست کردم و روی YouTubeم گذاشتم.

ساختن با JavaScript خیلی باحال بود. حالا دیگه فقط ظاهر صفحه نبود که می‌تونستم تغییرش بدم. می‌تونستم المنت‌ها رو تغییر بدم، بهشون رفتار بدم و یه جورایی بهشون شخصیت بدم. باحال بود!

بعد از اون یه چالش خیلی بزرگ‌تر برای خودم داشتم: ساخت ماشین حساب. ولی اصلا نمی‌خواستم یه ماشین حساب ساده بسازم که فقط کار کنه. می‌خواستم بتونه محاسبات پیچیده هم انجام بده، چندتا محاسبه پشت سر هم رو نمایش بده، خودش پرانتز بذاره، حافظه داشته باشه، محاسبات قبلی رو ذخیره کنه و کلی قابلیت دیگه. منطق ماشین حسابم حسابی پیچیده و باحال شد و خروجیش هم چیزی شد که تا امروز بهش افتخار می‌کنم.

بعد دیگه هرچی جلوتر می‌رفتم، برای یادگیری بیشتر و راحت‌تر شدن با JavaScript پروژه‌های جدیدتری برای خودم تعریف می‌کردم. از XO که هنوز یکی از تاپ‌ترین پروژه‌هامه، تا Spread Color، Quick Math، Sticky Scroll، Aim Lab و کلی پروژه و آزمایش دیگه.

کلا مدل یادگیریم اینجوری بود که وقتی یه چیز جدید یاد می‌گرفتم، فکر می‌کردم باهاش چی می‌تونم بسازم که باحال باشه. ترجیحا یه بازی، Simulation، Sandbox یا هر چیزی که بشه باهاش ور رفت و خودم از ساختنش خوشم بیاد. بعد هم می‌ساختمش و کلی باهاش حال می‌کردم!

هیچ‌وقت هم علاقه‌ای به ساختن سایت‌های خرید و فروش بورینگ نداشتم. نه برام جذاب بودن، نه حس می‌کردم دارم چیز خلاقانه‌ای می‌ساختم. برای همین بیشتر سراغ پروژه‌هایی می‌رفتم که خودم واقعا دوست داشتم بسازمشون.

بعدتر که تو CS Internship منتور فنی شدم، به خیلی از اینترن‌های دیگه هم JavaScript یاد دادم یا تو یادگیریش راهنماییشون کردم. برای بعضی‌هاشون حتی کلاس جدا برگزار می‌کردم، تمرین و تکلیف می‌دادم و کمکشون می‌کردم با مفاهیم مختلفش آشنا بشن.

JavaScript کلا یکی از ریشه‌های اصلی دنیای فنی منه. زبونیه که منطقش رو دوست دارم، باهاش راحتم و به نظرم فوق‌العاده قدرتمنده. سال‌های بعد Node.js، React، Expo، React Native و کلی تکنولوژی دیگه هم روش سوار شدن.

همه اینها از همون روزهایی شروع شد که تو راه دانشگاه روی شست دستم JS می‌نوشتم، یه دفتر ۶۰ صفحه‌ای داشتم و سعی می‌کردم هر روز بیشتر با این زبون آشنا بشم.

الان JavaScript دیگه یه دوست برام نیست. یه زبون حرف زدن برام هست. جزئی از من و نوع بیانم شده.

دوستش دارم. :)
