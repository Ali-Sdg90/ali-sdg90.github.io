کارم با Vite از اواخر سال ۲۰۲۴ شروع شد.

قبل از اون مدت زیادی پروژه‌های Reactم رو با Create React App می‌ساختم و به همون ساختار عادت کرده بودم.

وقتی با Vite آشنا شدم، خیلی سریع متوجه شدم هم راه‌اندازی پروژه باهاش راحت‌تره، هم تجربه توسعه سریع‌تر و سبک‌تری میده و هم از نظر Build و Performance برام انتخاب بهتریه.

برای همین تقریبا کامل از CRA روی Vite سوییچ کردم.

یاد گرفتنش هم نسبت به چیزهایی که از قبل بلد بودم خیلی پیچیده نبود. بیشتر لازم بود با ساختار پروژه، فایل vite.config، مدل Build و یه سری قابلیت‌های خود Vite آشنا بشم.

بعد از اون، تقریبا همه پروژه‌های جدید Reactم رو با Vite شروع کردم.

پروژه‌های بزرگ‌تری که برای ملک‌رادار ساختم، همین پورتفولیو و خیلی از پروژه‌هایی که بعد از اون دوره شروع کردم، همگی با Vite جلو رفتند.

الان کار کردن باهاش برام کاملا طبیعیه و معمولا برای شروع یه پروژه React جدید، انتخاب اولمه.
