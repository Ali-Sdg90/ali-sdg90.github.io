کارم با Vite از اواخر سال ۲۰۲۴ شروع شد.

قبل از اون مدت زیادی پروژه‌های Reactم رو با Create React App می‌ساختم و به همون ساختار عادت کرده بودم.

وقتی با Vite آشنا شدم، خیلی زود متوجه شدم که هم راه‌اندازی پروژه باهاش راحت‌تره، هم محیط توسعه خیلی سریع‌تر و سبک‌تری داره و هم فرآیند Build بهتری در اختیارم می‌ذاره. برای همین تقریبا کامل از CRA به Vite سوییچ کردم.

یاد گرفتنش هم نسبت به چیزهایی که از قبل بلد بودم خیلی پیچیده نبود. بیشتر لازم بود با ساختار پروژه، فایل vite.config، فرآیند Build و یه سری قابلیت‌های خود Vite آشنا بشم.

بعد از اون تقریبا همه پروژه‌های جدید Reactم رو با Vite شروع کردم. از پروژه‌های بزرگ‌تری که برای ملک‌رادار ساختم گرفته تا همین پورتفولیو و خیلی از پروژه‌های دیگه.

تو پروژه‌های ملک‌رادار و همین پورتفولیو، با تست‌نویسی تو محیط Vite هم آشنا شدم. خیلی با چیزی که قبلا با Jest کار کرده بودم فرق نداشت و برای همین یاد گرفتنش هم برام راحت بود.

تو همین پورتفولیو، وقتی تصمیم گرفتم SSG و Prerendering رو به پروژه اضافه کنم، بیشتر با ساختار Build و قابلیت‌های Vite درگیر شدم. تجربه جالبی بود که باعث شد فراتر از راه‌اندازی و توسعه معمول پروژه‌ها باهاش کار کنم.

تازگی یکی از پروژه‌های قدیمی CRAم رو دوباره باز کردم. باورم نمی‌شد چققققدر طول می‌کشید تا پروژه برای اولین بار بالا بیاد! مشخصا نه به اندازه پروژه‌های .NET، ولی نسبت به Vite که سرور توسعه رو تقریبا تو یه ثانیه بالا میاره، تفاوتش خیلی محسوس بود. :)

الان کار کردن با Vite برام کاملا طبیعیه و تقریبا بدون فکر کردن سراغش می‌رم. برای شروع یه پروژه React جدید هم معمولا انتخاب اولمه.
