اولین بار از طریق برنامه CS Internship با مفهوم REST API آشنا شدم.

اون موقع خیلی خوب متوجه نمی‌شدم دقیقا چه اتفاقی داره می‌افته. می‌دونستم یه Request فرستاده میشه و یه Response برمی‌گرده، ولی هنوز مدل فکری پشتش، Async بودن کار و نقش متدهای مختلف برام جا نیفتاده بود.

اولین استفاده واقعی من از API تو پروژه Rick and Morty Characters بود.

اونجا برای اولین بار مجبور شدم واقعا با گرفتن اطلاعات از یه API کار کنم و کم‌کم مفاهیمی مثل GET، Async بودن عملیات، منتظر موندن برای Response و مدیریت اطلاعاتی که برمی‌گرده برام قابل فهم‌تر شد.

بعد از اون تو پروژه‌های شخصی مختلف بیشتر تمرین کردم، ولی یادگیری اصلی من تو پروژه بزرگی بود که برای شرکت داده‌پردازی آزموده‌کاران ساختم.

یه Admin Panel بزرگ با React بود و یه دفعه بیشتر از ۶۰ API مختلف در اختیارم قرار گرفت که باید کل فرانت پروژه رو روی اون‌ها پیاده می‌کردم.

تقریبا با تمام عملیات‌های اصلی CRUD درگیر بودم. اطلاعات می‌گرفتم، می‌ساختم، تغییر می‌دادم و حذف می‌کردم و باید همه این‌ها رو به شکل مرتب و قابل نگهداری داخل یه پروژه خیلی بزرگ مدیریت می‌کردم.

برای همین ساختار APIها رو تو پروژه به شکل ماژولار پیاده کردم تا هر بخش جای مشخص خودش رو داشته باشه و با بزرگ‌تر شدن پروژه همه چیز قابل مدیریت بمونه.

یکی از بخش‌هایی که قبل از اون تجربه زیادی باهاش نداشتم Authentication بود.

خیلی از Requestها نیاز داشتند اطلاعات احراز هویت همراهشون ارسال بشه و تو این پروژه با Axios این بخش رو پیاده کردم. انقدر در طول پروژه با Request، Header، Authentication و Error Handling کار کردم که مدل ارتباط Frontend و Backend برام کاملا جا افتاد.

بعد از اون API تقریبا تو همه پروژه‌هام حضور داشت. از بات‌های CS Internship و Fabrexa AI گرفته تا اپ‌های Android و iOS، Backendها و ابزارهای داخلی مختلف.

بعدتر تو یکی از پروژه‌های تمرینیم با React Query و useQuery هم آشنا شدم و خیلی جذب راحتی کار باهاش شدم.

فکر کنم باید حداقل یه بار همه چیز رو با fetch دستی پیاده کرده باشی تا واقعا بفهمی Axios و مخصوصا React Query چقدر می‌تونند کارت رو راحت کنند.

وقتی خودت Loading، Data، Error، Retry، زمان Request و تغییر Stateهای مختلف رو هندل کرده باشی، تازه می‌فهمی این ابزارها دقیقا چه حجم کاری رو از دوشت برمی‌دارند.

REST API برای من یکی از اون مفاهیمیه که فقط با خوندن درباره‌ش واقعا یاد گرفته نمیشه.

باید تو پروژه‌های واقعی باهاش درگیر بشی تا مدل فکر کردنش برات جا بیفته.

من الان باهاش کاملا راحتم و ارتباط با APIها رو یکی از طبیعی‌ترین بخش‌های ساخت یه پروژه واقعی می‌بینم.
