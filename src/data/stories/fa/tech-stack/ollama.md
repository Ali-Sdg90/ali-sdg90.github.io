کارم با Ollama تو سال ۲۰۲۶ و از یه نیاز مشخص تو پروژه Fabrexa AI Ollama شروع شد.

می‌خواستم یه بات تلگرام بسازم که به‌جای وابسته بودن به سرویس‌های آنلاین هوش مصنوعی، بتونه به مدل‌هایی که روی سیستم خودم به‌صورت لوکال اجرا می‌شن وصل بشه.

اونجا با Ollama آشنا شدم و دیدم چقدر ابزار قدرتمند و کار راه‌بندازیه. هم اجرای مدل‌های لوکال رو خیلی راحت می‌کرد، هم یه API داخلی داشت که می‌تونستم مستقیم از پروژه خودم بهش وصل بشم.

با توجه به نیازم و قدرت سیستمم، مدل‌های مختلف رو از Hugging Face دانلود می‌کردم، وارد Ollama می‌کردم و بعد Fabrexa AI Bot از طریق API خود Ollama بهشون دسترسی داشت. بات می‌تونست پیام رو برای مدل لوکال انتخاب‌شده بفرسته و جوابش رو مستقیم تو تلگرام برگردونه.

یه بار هم برای یه استفاده خاص، افتاده بودم دنبال مدل‌های مختلف تو Hugging Face. فکر کنم حدود ۶ تا مدل لوکال مختلف دانلود کردم که از نظر تکنولوژی و نحوه ساخته شدن با هم فرق داشتن. با کمک Ollama همشون رو اجرا می‌کردم، تستشون می‌کردم و باهاشون کار می‌کردم تا ببینم هرکدوم چجوری رفتار می‌کنن و چه خروجی‌ای می‌دن.

این قسمت از کار کردن با مدل‌های لوکال رو خیلی دوست داشتم. اینکه می‌تونستم مدل‌های مختلف رو روی سیستم خودم اجرا کنم، باهاشون آزمایش کنم و بدون وابستگی به یه سرویس آنلاین ازشون استفاده کنم، خیلی باحال بود.

بعدتر، موقع قطعی سراسری اینترنت تو ایران، Ollama یه استفاده خیلی مهم‌تر هم برام پیدا کرد.

خداروشکر علی قبلش با Ollama آشنا شده بود و یه مدل DeepSeek هم روی سیستمش داشت! تو اون حدود یک ماهی که اینترنت قطع بود و دسترسی به LLMهای آنلاین نداشتم، با کمک همین Ollama نیازم به LLM رو هندل می‌کردم.

البته کیفیتش اصلا به پای مدل‌های آنلاین نمی‌رسید، ولی تو اون شرایط خیلی به کارم اومد. حداقل یه مدل داشتم که می‌تونستم روی سیستم خودم اجراش کنم و برای کارهایی که نیاز داشتم ازش کمک بگیرم.

کلا Ollama برام ابزار خیلی باحال و کاربردی‌ایه. از ساخت بات تلگرام و آزمایش مدل‌های مختلف گرفته تا استفاده واقعی از یه LLM تو شرایطی که دسترسی به مدل‌های آنلاین نداشتم.

کار کردن با مدل‌های لوکال و وصل کردنشون به پروژه‌های خودم رو خیلی راحت‌تر کرد و هنوز هم از ابزارهاییه که دوست دارم باهاش ور برم. :)
