# Security Policy

## Supported versions

Security updates apply to the latest live release and the current `main` branch.
Older releases are not maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a potential security vulnerability.

Email [ali.sdg.dev90@gmail.com](mailto:ali.sdg.dev90@gmail.com) with the subject
`[Security] Ali's Portfolio` and include:

- A clear description of the issue.
- Steps to reproduce it.
- The potential impact.
- Any useful screenshots, logs, or proof of concept.

Please avoid accessing private data, disrupting the live site, or exploiting the
issue beyond what is necessary to demonstrate it.

The report will be reviewed as soon as reasonably possible. If the issue is
confirmed, a fix and any appropriate disclosure will be coordinated with the
reporter.

For visual, content, or general functional bugs, use the repository's bug report
template instead.
