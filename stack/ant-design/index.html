Ant Design

UI Components & Complex Interfaces

Used Ant Design extensively across large production dashboards, hiring tasks, internal tools, and long-running projects, with a strong focus on deep component customization and complex data-driven interfaces.

Where It Helps

  • Building complex dashboards, tables, forms, calendars, and data-heavy interfaces
  • Creating polished and consistent interfaces from a large, well-designed component system
  • Deeply customizing components and adapting their structure and behavior to specific product designs

Story

Ant Design has kept showing up throughout my career.

My first experience with it was in 2024 at MelkRadar.

The company had taken on a very large existing project that was already built with Ant Design, and we needed to add new features to it. That was my first real exposure to the library.

After that, like I usually do when learning something new, I created a scratch project for myself and started experimenting with different Ant Design components to understand how they worked and what the library could do.

That repository later became more than just a playground.

When I was applying to Dadeh Pardazi Azmoudeh Karan, they gave me one of their website pages as a hiring task and asked me to recreate it.

I built and delivered that page using Ant Design, and kept it inside the same repository alongside my earlier experiments.

The GitHub Pages deployment of that repository now opens directly to the page I built for that hiring task, so the repository ended up documenting both my learning process and an actual piece of work I delivered.

Later, after joining the company, I was given a large React admin panel where almost the entire interface was built around Ant Design.

That's where I really became comfortable with it.

I worked heavily with tables, forms, page layouts, and many of the components needed for a large data-driven dashboard.

Ant Design is honestly one of my favorite UI libraries.

It's huge, polished, and incredibly thoughtful. There are so many small details in its components that you can really feel how much work went into designing the system.

The difficult part is customization.

A lot of the designs I worked with needed the components to look or behave very differently from their defaults. Getting there often meant digging through the component structure, finding the right internal styles and elements, and manually overriding or rebuilding parts of them.

It's a lot of work, and a large part of my experience with Ant Design has been exactly that kind of deep customization.

But I still really enjoy working with it, and the final result of the company's admin panel turned out very polished.

Later, the CS Internship program needed a calendar, and I volunteered to build it.

I was pleasantly surprised to find that Ant Design had a Calendar component too, so I started from there.

The original component was designed around an English calendar structure, while we needed a Persian experience with our own week layout and behavior.

That required a lot of customization, but the result became one of my favorite projects.

The calendar is still actively used in the program today.

Ant Design feels big, powerful, detailed, and carefully designed.

I'm pretty comfortable with it now, and despite how much work deep customization can sometimes take, it's still one of the UI libraries I genuinely enjoy using.

تو مسیر کاری من بارها به سمت Ant Design کشیده شدم.

اولین بار تو سال ۲۰۲۴ و تو یکی از پروژه‌های ملک‌رادار باهاش برخورد کردم.

یه پروژه خیلی بزرگ به شرکت رسیده بود که از قبل با Ant Design ساخته شده بود و ما باید یه سری Feature جدید بهش اضافه می‌کردیم. اون اولین تجربه واقعی من با این Library بود.

بعدش مثل تقریبا همه مسیرهای یادگیریم، برای خودم یه پروژه چرک‌نویس ساختم و شروع کردم کامپوننت‌های مختلفش رو امتحان کردن تا بهتر بفهمم چجوری کار می‌کنه و چه چیزهایی در اختیارم می‌ذاره.

ولی اون ریپازیتوری بعدا فقط یه پروژه تمرینی نموند.

وقتی برای استخدام تو شرکت داده‌پردازی آزموده‌کاران اقدام کردم، برای تست یه صفحه از سایت خودشون رو بهم دادند و خواستند پیاده‌سازیش کنم.

اون صفحه رو با Ant Design ساختم و تحویل دادم و بعد هم داخل همون ریپازیتوری‌ای که برای تمرین ساخته بودم نگهش داشتم.

الان GitHub Pages اون ریپو هم مستقیم همون صفحه‌ای رو نشون می‌ده که برای تست استخدام ساخته بودم. برای همین اون ریپو هم مسیر تمرین و یادگیریم رو داره و هم یه خروجی واقعی که تحویل دادم.

بعدتر که وارد شرکت شدم، پروژه بزرگ Admin Panel رو به من سپردند و تقریبا کل UI اون پروژه هم روی Ant Design ساخته شده بود.

اونجا دیگه خیلی جدی‌تر باهاش کار کردم؛ از ساخت Tableهای مختلف و فرم‌ها گرفته تا Layout صفحه‌ها و بخش‌های مختلف یه پنل بزرگ.

Ant Design برای من واقعا یکی از Libraryهای UI مورد علاقه‌مه.

خیلی بزرگ، باکیفیت و فکرشده‌ست. جزئیات ریز خیلی زیادی داره و وقتی باهاش کار می‌کنم واقعا حس می‌کنم برای رفتار و ظاهر حتی قسمت‌های کوچیکش هم حسابی وقت گذاشته شده.

بخش سخت کار برای من معمولا Custom کردن کامپوننت‌ها بوده.

خیلی وقت‌ها Design دقیقا چیزی نیست که Ant Design به شکل پیش‌فرض می‌ده و برای رسیدن به خروجی مورد نظر باید وارد ساختار خود کامپوننت‌ها بشم، Styleها رو دنبال کنم و قسمت‌های مختلفش رو دستی تغییر بدم.

کار پرزحمتیه و بخش زیادی از تجربه من با Ant Design دقیقا همین Customizationهای عمیق بوده.

ولی با وجود این هنوز خیلی دوستش دارم و خروجی پروژه شرکت هم در نهایت خیلی باکیفیت و حرفه‌ای شد.

بعدتر تو CS Internship به یه Calendar برای برنامه نیاز داشتیم و من گفتم خودم می‌سازمش.

وقتی دیدم Ant Design خودش Calendar هم داره، تصمیم گرفتم از همون استفاده کنم.

ساختار اصلی Calendar برای حالت انگلیسی طراحی شده بود، ولی ما یه Calendar فارسی با ساختار هفته و نمایش مناسب خودمون می‌خواستیم.

برای همین مجبور شدم خیلی از قسمت‌هاش رو Custom کنم و رفتار و ظاهرش رو تغییر بدم تا به چیزی که نیاز داشتیم برسیم.

در نهایت خروجی خیلی خوبی ازش دراومد و هنوز هم به‌صورت دائمی تو برنامه استفاده می‌شه.

Ant Design برای من یه Library خیلی بزرگ، قدرتمند، ظریف و باحاله.

باهاش نسبتا راحتم، از کار کردن باهاش لذت می‌برم و با اینکه Custom کردنش گاهی واقعا پرزحمته، هنوز یکی از Libraryهای UI مورد علاقه‌مه.
