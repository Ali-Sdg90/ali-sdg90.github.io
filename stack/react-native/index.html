React Native

Cross-Platform Mobile Development

Used React Native and Expo to build and ship a real iOS product with native device capabilities, authentication, AI integrations, subscriptions, and App Store distribution.

Where It Helps

  • Building mobile applications with a JavaScript and React-based development model
  • Accessing native device capabilities like the camera, microphone, and photo library through Expo and native APIs
  • Connecting mobile apps to authentication, cloud backends, AI services, and subscription systems

Story

My main experience with React Native came from one specific project in 2025: SettleItGPT.

I built the project with a friend, and the entire application was developed with React Native and Expo.

SettleItGPT was a fairly complex iOS application. Users could create accounts, their data was stored in Firebase, and the app used native device capabilities like the camera, microphone, and photo library.

Information collected from the user was sent to an LLM, the model generated a response, and in parts of the application another model converted the generated text into speech so the result could be delivered directly inside the app.

The app also had a subscription system, with purchases handled through Stripe.

It wasn't an easy project for me.

Unlike many other technologies I learned gradually by experimenting with smaller projects first, with React Native I was dropped almost directly into a real product and had to learn whatever the project needed while I was building it.

Because of that, React Native, Expo, and especially some of the native parts caused me plenty of trouble along the way.

But the final result was really good.

The app worked, all the different systems came together, and we eventually managed to publish the finished product on the Apple App Store.

My relationship with React Native is much more neutral than my relationship with something like React.

I never really went through the slow, step-by-step learning process I usually enjoy with a technology. I mostly learned it because the project demanded it and kept moving forward from there.

But that project also proved to me that I can work with React Native and take a relatively complex mobile product all the way to release.

At the end of the day, React Native is still built around JavaScript and a way of thinking I'm already very comfortable with.

So it may not be one of my favorite technologies, but if another project needs it, I know I can work with it and get the job done.

تجربه اصلی من با React Native تقریبا محدود به یه پروژه مشخص تو سال ۲۰۲۵ بود: SettleItGPT.

این پروژه رو با یکی از دوست‌هام می‌ساختیم و کل اپ با React Native و Expo پیاده‌سازی شده بود.

SettleItGPT یه اپ iOS نسبتا پیچیده بود. کاربر می‌تونست داخلش اکانت بسازه، اطلاعاتش روی Firebase ذخیره می‌شد و اپ از قابلیت‌های Native گوشی مثل دوربین، میکروفون و گالری هم استفاده می‌کرد.

اطلاعاتی که از کاربر گرفته می‌شد برای مدل LLM فرستاده می‌شد، جواب مدل برمی‌گشت و در بخش‌هایی از برنامه یه مدل دیگه هم از متن خروجی TTS می‌ساخت تا نتیجه داخل خود اپ در اختیار کاربر قرار بگیره.

اپ حتی سیستم اشتراک هم داشت و خرید Subscription از طریق Stripe انجام می‌شد.

برای من پروژه ساده‌ای نبود.

برخلاف خیلی از تکنولوژی‌های دیگه‌ای که آروم آروم یادشون گرفتم، پروژه کوچیک ساختم و بعد کم‌کم رفتم سمت چیزهای بزرگ‌تر، اینجا تقریبا مستقیم افتادم وسط یه پروژه واقعی و مجبور شدم هر چیزی که نیاز داشتیم رو همون موقع یاد بگیرم و پیاده کنم.

همین باعث شد کار با React Native و مخصوصا بخش‌های Native و Expo بعضی وقت‌ها حسابی به دردسرم بندازه.

ولی در نهایت خروجی خیلی خوبی از پروژه گرفتیم.

اپ واقعا کار می‌کرد، قابلیت‌های مختلفش کنار هم قرار گرفته بودند و تونستیم نسخه نهایی رو روی Apple App Store منتشر کنیم.

رابطه‌م با React Native خیلی خنثی‌تر از چیزیه که مثلا با React دارم.

اون مسیر مرحله‌به‌مرحله‌ای که معمولا دوست دارم برای شناخت یه تکنولوژی طی کنم رو باهاش نداشتم و بیشتر به خاطر نیاز پروژه مجبور شدم سریع واردش بشم و جلو برم.

ولی همین پروژه بهم ثابت کرد که می‌تونم باهاش کار کنم و یه محصول واقعی و نسبتا پیچیده رو هم باهاش به نتیجه برسونم.

در نهایت React Native هنوز روی همون JavaScript و مدل فکری‌ای ساخته شده که باهاش خیلی راحتم.

برای همین شاید تکنولوژی مورد علاقه‌م نباشه، ولی اگه دوباره پروژه‌ای بهش نیاز داشته باشه، می‌دونم می‌تونم باهاش کارم رو پیش ببرم.
