Vite

Frontend Build Tooling

Use Vite as my default setup for modern React projects, with a fast development experience, simple configuration, and efficient builds.

Where It Helps

  • Starting React projects with a fast and lightweight development environment
  • Managing project configuration, builds, aliases, plugins, and environment settings
  • Keeping development and production workflows simple, modern, and performant

Story

I started working with Vite near the end of 2024.

Before that, I had spent a long time creating my React projects with Create React App and was pretty used to that setup.

Once I tried Vite and saw how much faster, simpler, and lighter the development experience was, switching away from CRA felt pretty natural.

There wasn't a huge learning curve for me. I mostly needed to get familiar with the project structure, vite.config, the build process, and some of the features Vite gives you around configuration and development.

After that, I started using Vite for almost every new React project I built.

Larger projects I worked on for MelkRadar, this portfolio, and many of the projects I've built since then have all used Vite.

At this point, working with it feels completely natural to me.

If I'm starting a new React project today, Vite is my first choice.

قبل از اون مدت زیادی پروژه‌های Reactم رو با Create React App می‌ساختم و به همون ساختار عادت کرده بودم.

وقتی با Vite آشنا شدم، خیلی سریع متوجه شدم هم راه‌اندازی پروژه باهاش راحت‌تره، هم تجربه توسعه سریع‌تر و سبک‌تری میده و هم از نظر Build و Performance برام انتخاب بهتریه.

برای همین تقریبا کامل از CRA روی Vite سوییچ کردم.

بعد از اون، تقریبا همه پروژه‌های جدید Reactم رو با Vite شروع کردم.

پروژه‌های بزرگ‌تری که برای ملک‌رادار ساختم، همین پورتفولیو و خیلی از پروژه‌هایی که بعد از اون دوره شروع کردم، همگی با Vite جلو رفتند.
