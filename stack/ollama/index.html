Ollama

Local LLM Runtime

Used Ollama to run and manage local LLMs and connect them to Fabrexa AI Bot through its local API.

Where It Helps

  • Running different LLMs locally without depending on external AI APIs
  • Exposing local models through a simple API for use inside applications
  • Testing and switching between models based on system resources and project needs

Story

I started working with Ollama in 2026 because of a specific need in my Fabrexa AI Ollama project.

I wanted to build a Telegram bot that could connect to AI models running locally on my own computer instead of depending on online AI services.

That's when I discovered Ollama and realized how powerful and useful it was. It made running local models much easier, and it also had a local API that I could connect to directly from my own project.

Depending on what I needed and what my computer could handle, I would download different models from Hugging Face, import them into Ollama, and let Fabrexa AI Bot access them through Ollama's API. The bot could send a message to the selected local model and return its response directly in Telegram.

At one point, I was also looking for different models on Hugging Face for a particular use case. I think I downloaded around six different local models, built using different technologies and approaches. I used Ollama to run, test, and experiment with all of them to see how each one behaved and what kind of responses it produced.

I really enjoyed that part of working with local models. Being able to run different models on my own computer, experiment with them, and use them without depending on an online service was pretty cool.

Later, during a nationwide internet shutdown in Iran, Ollama became useful to me in a completely different way.

Thankfully, I had already discovered Ollama and downloaded a local DeepSeek model! During that roughly one-month period when the internet was cut off and I couldn't access online LLMs, I used Ollama to cover my day-to-day LLM needs.

Of course, the quality wasn't anywhere near what I was used to from online models, but it was really useful in those circumstances. At least I had a model I could run on my own computer and use for the things I needed.

Overall, Ollama has been a really cool and practical tool for me, from building a Telegram bot and experimenting with different models to relying on a local LLM when I couldn't access online ones.

It made running local models and connecting them to my own projects much easier, and it's still one of those tools I enjoy playing around with. :)

کارم با Ollama تو سال ۲۰۲۶ و از یه نیاز مشخص تو پروژه Fabrexa AI Ollama شروع شد.

می‌خواستم یه بات تلگرام بسازم که به‌جای وابسته بودن به سرویس‌های آنلاین هوش مصنوعی، بتونه به مدل‌هایی که روی سیستم خودم به‌صورت لوکال اجرا می‌شن وصل بشه.

اونجا با Ollama آشنا شدم و دیدم چقدر ابزار قدرتمند و کار راه‌بندازیه. هم اجرای مدل‌های لوکال رو خیلی راحت می‌کرد، هم یه API داخلی داشت که می‌تونستم مستقیم از پروژه خودم بهش وصل بشم.

با توجه به نیازم و قدرت سیستمم، مدل‌های مختلف رو از Hugging Face دانلود می‌کردم، وارد Ollama می‌کردم و بعد Fabrexa AI Bot از طریق API خود Ollama بهشون دسترسی داشت. بات می‌تونست پیام رو برای مدل لوکال انتخاب‌شده بفرسته و جوابش رو مستقیم تو تلگرام برگردونه.

یه بار هم برای یه استفاده خاص، افتاده بودم دنبال مدل‌های مختلف تو Hugging Face. فکر کنم حدود ۶ تا مدل لوکال مختلف دانلود کردم که از نظر تکنولوژی و نحوه ساخته شدن با هم فرق داشتن. با کمک Ollama همشون رو اجرا می‌کردم، تستشون می‌کردم و باهاشون کار می‌کردم تا ببینم هرکدوم چجوری رفتار می‌کنن و چه خروجی‌ای می‌دن.

این قسمت از کار کردن با مدل‌های لوکال رو خیلی دوست داشتم. اینکه می‌تونستم مدل‌های مختلف رو روی سیستم خودم اجرا کنم، باهاشون آزمایش کنم و بدون وابستگی به یه سرویس آنلاین ازشون استفاده کنم، خیلی باحال بود.

بعدتر، موقع قطعی سراسری اینترنت تو ایران، Ollama یه استفاده خیلی مهم‌تر هم برام پیدا کرد.

خداروشکر علی قبلش با Ollama آشنا شده بود و یه مدل DeepSeek هم روی سیستمش داشت! تو اون حدود یک ماهی که اینترنت قطع بود و دسترسی به LLMهای آنلاین نداشتم، با کمک همین Ollama نیازم به LLM رو هندل می‌کردم.

البته کیفیتش اصلا به پای مدل‌های آنلاین نمی‌رسید، ولی تو اون شرایط خیلی به کارم اومد. حداقل یه مدل داشتم که می‌تونستم روی سیستم خودم اجراش کنم و برای کارهایی که نیاز داشتم ازش کمک بگیرم.

کلا Ollama برام ابزار خیلی باحال و کاربردی‌ایه. از ساخت بات تلگرام و آزمایش مدل‌های مختلف گرفته تا استفاده واقعی از یه LLM تو شرایطی که دسترسی به مدل‌های آنلاین نداشتم.

کار کردن با مدل‌های لوکال و وصل کردنشون به پروژه‌های خودم رو خیلی راحت‌تر کرد و هنوز هم از ابزارهاییه که دوست دارم باهاش ور برم. :)
