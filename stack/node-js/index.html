Node.js

Backend, Bots & Automation

Used Node.js to build Telegram bots, backend services, local automation tools, server utilities, and integrations across personal, open-source, and production projects.

Where It Helps

  • Building backend services and connecting applications, APIs, databases, and external systems
  • Creating Telegram bots, background tools, and automation that can run independently of the browser
  • Working with files, processes, local services, APIs, and lightweight server-side applications

Story

I started working with Node.js in 2023.

I've always liked building things that can work automatically on their own. At the time, I was already comfortable with JavaScript and React, but I wanted to build tools for my own computer that weren't limited to running inside a browser.

That's what led me to Node.js.

Like with most technologies I learned, I created a repository called Learning-NodeJS and used it as a scratchpad for experimenting, breaking things, rebuilding them, and learning how everything worked.

Most of my learning came from different YouTube videos, and I tried not to just watch tutorials. I would give myself small projects and use what I had learned to actually build something.

What really got me interested in Node.js was building Telegram bots.

I built three bots for the CS Internship program, and two of them became part of the program's regular workflow and were used for a long time.

I really enjoyed building those bots because I wasn't just making something that existed on a page anymore. It could keep running, receive messages, make decisions, and actually do something on its own.

The mental model of Node.js never felt too unfamiliar to me. It was still JavaScript, but now I could work with files, create and modify them, run processes, communicate with other services, and use a few new concepts and rules around server-side development.

Because of that, I became comfortable with it pretty quickly.

I also built an internal tool called CS Server Waker for the program.

It ran on Windows and started automatically when the system booted. At different times, it would send requests to the program's servers and make sure they were still available. If one of the servers had gone down, it would use the user's system to try to wake it back up.

That was exactly the kind of tool that made me enjoy Node.js in the first place: a small application quietly running in the background and doing its job without someone constantly having to watch it.

For a while, I also explored building APIs and documenting them with Swagger. It was useful and taught me a lot, although compared to building bots and automation, that part felt a little more dry to me.

Later, I started using Node.js for more practical backend projects.

For one of my projects at MelkRadar, I built a backend that received data from an Android application I had also built, stored it in a simple database, processed what was needed, and then sent the result to the team through Telegram.

I also used Node.js for my personal Fabrexa AI project.

Fabrexa is a locally running Telegram bot connected to Ollama. It lets me interact with local LLMs directly through Telegram using my own prompts and configuration.

The bot also supports short-term and long-term memory, keeps conversation context, and can switch between different models and personalities.

Node.js is now one of those technologies I'm very comfortable working with.

Whether I need a small internal utility, a bot, some background automation, or a lightweight backend connecting a few different systems together, I can usually get where I need to go with it pretty comfortably.

And I think the reason I still like it is the same reason I started learning it in the first place: it lets me use a language I already know to build things that can actually do work outside the browser.

شروع کارم با Node.js برمی‌گرده به سال ۲۰۲۳.

من همیشه دوست داشتم چیزهایی بسازم که خودشون اتومات کار کنند. اون موقع JavaScript و React رو تا حد خوبی یاد گرفته بودم، ولی دلم می‌خواست بتونم یه سری ابزار داخلی برای خود لپ‌تاپم بسازم که فقط محدود به مرورگر نباشند و خودشون کار انجام بدن.

برای همین رفتم سراغ Node.js.

مثل بیشتر تکنولوژی‌هایی که یاد گرفتم، یه ریپازیتوری به اسم Learning-NodeJS ساختم و ازش به‌عنوان چرک‌نویس برای تست کردن، خراب کردن، دوباره ساختن و یاد گرفتن استفاده کردم.

بیشتر مسیر یادگیریم با ویدئوهای مختلف YouTube جلو می‌رفت و سعی می‌کردم به‌جای فقط دیدن آموزش، برای خودم پروژه‌های کوچیک تعریف کنم و چیزهایی که یاد می‌گیرم رو همونجا استفاده کنم.

چیزی که واقعا من رو جذب Node.js کرد، ساختن بات تلگرام باهاش بود.

برای برنامه CS Internship سه بات ساختم که دوتاشون وارد روند دائمی برنامه شدند و مدت زیادی استفاده شدند. ساختن این بات‌ها واقعا برام لذت‌بخش بود، چون یه چیزی می‌ساختم که فقط روی صفحه نبود؛ خودش اجرا می‌شد، پیام می‌گرفت، تصمیم می‌گرفت و یه کار واقعی انجام می‌داد.

Node.js از نظر مدل فکری برای من خیلی غریبه نبود. هنوز JavaScript بود، فقط این بار یه سری قابلیت جدید مثل کار با فایل‌ها، ساختن و خوندن و تغییرشون، اجرای پروسه‌ها و یه سری قوانین و مفاهیم جدید هم بهش اضافه شده بود.

برای همین خیلی سریع تونستم با مدل کار کردنش ارتباط بگیرم.

یه ابزار داخلی دیگه هم به اسم CS Server Waker برای برنامه ساختم.

این ابزار روی Windows اجرا می‌شد و همراه بالا اومدن سیستم شروع به کار می‌کرد. تو زمان‌های مختلف به سرورهای برنامه Request می‌فرستاد و بررسی می‌کرد که هنوز در دسترس هستند. اگه یکی از سرورها خاموش یا از دسترس خارج شده بود، از طریق سیستم کاربر تلاش می‌کرد دوباره بیدارش کنه.

این هم دقیقا از همون مدل ابزارهایی بود که Node.js رو به خاطرشون دوست داشتم. یه برنامه کوچیک که تو پس‌زمینه کار خودش رو انجام می‌داد و نیاز نبود کسی مدام حواسش بهش باشه.

یه دوره‌ای هم با Node.js رفتم سمت ساخت API و کار با Swagger. تجربه باحالی بود و چیزهای خوبی بهم یاد داد، هرچند نسبت به ساخت ابزار و بات، اون بخش برای من یکم خشک‌تر بود.

بعدتر از Node.js برای ساخت بک‌اند پروژه‌های واقعی‌تر هم استفاده کردم.

برای یکی از پروژه‌های شرکت ملک‌رادار، بک‌اندی ساختم که اطلاعات رو از اپ اندرویدی‌ای که خودم ساخته بودم دریافت می‌کرد، تو یه دیتابیس ساده ذخیره می‌کرد و بعد نتیجه مورد نیاز رو از طریق تلگرام برای تیم می‌فرستاد.

برای پروژه شخصی Fabrexa AI هم از Node.js استفاده کردم.

Fabrexa یه بات تلگرام لوکاله که به Ollama وصل میشه و اجازه میده با مدل‌های LLM روی سیستم خودم، با پرامپت‌ها و تنظیمات دلخواه، مستقیم از داخل تلگرام صحبت کنم.

بات حافظه کوتاه‌مدت و بلندمدت هم داره و می‌تونه Context مکالمه رو نگه داره و بین مدل‌ها و شخصیت‌های مختلف جابه‌جا بشه.

Node.js برای من الان جزو اون تکنولوژی‌هاییه که خیلی باهاش راحتم.

چه بخوام یه ابزار کوچیک داخلی بسازم، چه بات، چه یه بک‌اند ساده برای وصل کردن چند سیستم به هم، معمولا خیلی راحت می‌تونم باهاش کارم رو جلو ببرم.

و فکر کنم چیزی که از اول من رو سمتش کشوند هنوز هم همونه: اینکه با یه زبان آشنا بتونم چیزی بسازم که خودش بیرون از مرورگر کار واقعی انجام بده.
